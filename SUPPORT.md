# Support

TerraTools LT is currently a release candidate / public beta project.

## Bug reports and feature requests

Use the GitHub Issues page for reproducible bugs and feature requests.

For a bug, include:

- TerraTools version
- AutoCAD LT version
- Windows version
- exact command or UI workflow
- expected behavior
- actual behavior
- the smallest safe reproduction steps
- relevant `TTDEBUG`, `TTDEVSMOKE`, or `TTQACHECK` output

Do **not** upload confidential drawings, client data, project addresses, proprietary office standards, credentials, or licensed third-party content to a public issue.

## Engineering limitations

TerraTools is not a substitute for professional engineering judgment. Irrigation calculations are transparent productivity helpers and must be reviewed against project requirements, manufacturer data, codes, and applicable professional standards.

## Compatibility

The target is AutoCAD LT 2024+ on Windows. The release checklist documents which versions and GUI workflows have actually been exercised. A target version is not the same as a claim that every release has been exhaustively tested on every configuration.

## No support SLA

This open-source release has no guaranteed response time, uptime commitment, or commercial support SLA.
