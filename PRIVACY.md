# Privacy

TerraTools LT runtime is designed to operate locally.

The application itself does not require:

- a TerraTools account
- cloud project storage
- runtime telemetry
- advertising identifiers
- analytics services
- remote database services

Project data, user libraries, preferences, and the optional WFO plant database are stored locally according to the documented project/data model.

If you use GitHub to download releases, browse documentation, file issues, or view the project website, GitHub's own services and privacy practices apply independently of TerraTools.

Do not attach confidential client/project files to public bug reports.
