One toolkit, one project model

Production workflows without leaving AutoCAD LT.

TerraTools keeps geometry ordinary and editable while adding project identity, reusable records, schedules, verification, and domain-specific tools.

P

Planting

Project Plants, library search, variants, path/array/fill placement, mixes, density areas, labels, costs, schedules, favorites, and recent plants.

W

Work Areas

Create explicit project scopes, assign smart objects, control new placements, filter schedules, and retain stable area identities.

D

Details & site

Reference notes, callouts, measurements, concept boundaries, searchable detail records, renumbering, indexes, and user libraries.

L

Lighting

Fixture palettes, placement, matching, circuits, transformers, connected loads, voltage-drop helpers, verification, and schedules.

I

Directed pipe networks, stations, controllers, equipment, flow analysis, Hazen-Williams sizing, pressure paths, coverage, drip demand, and schedules.

Verification, duplicate-identity reconciliation, backups, deliberate recovery, project packages, diagnostics, and deterministic calculation checks.

Optional open plant data

Search a massive taxonomy without loading it all at startup.

TerraTools can use the World Flora Online June 2026 release as an optional local plant source. Search is sharded and lazy, so the full dataset stays out of startup memory.

Important: WFO is a taxonomy source, not a horticultural specification library. Review suitability, size, culture, and design criteria for your project.

Get started

Install in a few deliberate steps.

  1. 1
    Download TerraTools LT

    Use the latest GitHub release and extract the folder somewhere permanent.

  2. 2
    Trust the install folder

    Add the TerraTools folder and subfolders to AutoCAD LT's Support File Search Path and Trusted Locations.

  3. 3
    Load TerraTools.lsp

    Run APPLOAD, select TerraTools.lsp, then type TT.

  4. 4
    Run the checks

    Use TTRELOAD, TTDEVSMOKE, and TTQACHECK before production work.

  5. 5
    Optional: install WFO data

    Place the production plant package so data/plants/production/manifest.dat exists below the TerraTools root.

Positioning

Built for the AutoCAD LT gap.

TerraTools LT is an independent project. It is not affiliated with, endorsed by, or a copy of Land F/X. It uses original code, UI, formats, sample content, and a documented clean-room data model.

TerraTools LT focuses on
  • AutoCAD LT compatibility
  • Ordinary editable DWG entities
  • Local/offline project data
  • Open-data plant search
  • Transparent, inspectable calculations
Not currently claimed
  • Full Land F/X feature parity
  • Manufacturer-certified irrigation catalogs
  • Large curated production block/content libraries
  • Cloud multi-user synchronization
  • CAD-to-3D platform synchronization
