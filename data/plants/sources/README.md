# Plant source files

Place user-downloaded source files here only for local development. Large third-party downloads should not be committed without a recorded license and a deliberate repository policy.

The supported USDA workflow is: download the Complete PLANTS Checklist CSV from the official USDA PLANTS downloads page, run `TTIMPORTUSDA`, and write a normalized `.dat` file. The source file itself is not required at TerraTools runtime after conversion.
